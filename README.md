# Estate — Pelekh Agency Real Estate Landing Page

A fully responsive landing page for a real estate investment agency, showcasing property listings, investment opportunities, and client testimonials with a clean, modern UI.

## 🔗 Live Demo

[https://kirillchacha.github.io/estate/home.html](https://kirillchacha.github.io/estate/home.html)

## ✨ Features

- **Hero section** — eye-catching intro with clear calls-to-action for prospective investors
- **Investment opportunities showcase** — a curated portfolio of apartments, townhouses, and commercial properties with images, titles, and specifications
- **About section** — company background and track record presented to build trust with visitors
- **Investment benefits** — key advantages of investing (low entry price, high returns, low taxes) presented in an easy-to-scan layout
- **Testimonials** — client reviews with star ratings for social proof
- **Contact form** — lead-capture form for consultation requests (name, phone, email)
- **Newsletter subscription** — footer sign-up for updates and news
- **Responsive navigation** — clean top menu that adapts across screen sizes
- **Fully responsive design** — optimized layout for desktop, tablet, and mobile

## 🛠️ Tech Stack

- **HTML5** — semantic markup for structure and SEO
- **CSS** — custom styling for layout, typography, and responsiveness
- **JavaScript** — interactivity and dynamic UI behavior
- **Custom fonts & icons** — for a polished, on-brand visual style

## 🚀 Getting Started

No build tools or installation required — this is a static site.

1. Clone the repository:
   ```bash
   git clone https://github.com/kirillchacha/estate.git
   ```
2. Open `home.html` (or `index.html`) directly in your browser, or serve the folder with any static file server.
